# 魔精大融合

无需安装依赖的静态网页游戏。用浏览器打开 `index.html` 即可游玩。当前版本包含主菜单、模式选择、暂停流程、永久图鉴、规则说明与新手引导。无尽模式启用路线Ⅰ–Ⅲ，保留普通连击与单只预告；双链融合启用路线Ⅳ–Ⅴ，并包含双预告、交替共鸣、平衡倍率、短期目标和五阶成对清除。游玩信息集中在容器顶部，同时保留 6 秒自动投放、危险线及稀有魔精反馈。物理模拟使用项目内置的 Matter.js 0.20.0，不依赖外部 CDN。

两种模式的最高分分别保存；图鉴收集进度和引导完成状态由两种模式共用。游戏界面与图鉴不会展示素材原始编号。

## 匿名最高排行榜

游戏包含无尽模式与双链融合两张匿名设备最高排行榜。排行榜使用浏览器本地生成的随机安装身份，不要求玩家登录；清除浏览器数据或更换浏览器后会形成新的匿名身份。排行榜接口尚未配置时，游戏仍会保存本地最高分，并缓存待同步成绩。

Cloudflare Worker 与 D1 后端位于 `worker` 目录。完成部署后，将 Worker 的 HTTPS 地址填入 `leaderboard-config.js` 即可启用全球排行榜。详细步骤见 `worker/README.md`。

## GitHub Pages 部署

将整个文件夹推送到 GitHub 仓库后，在仓库 **Settings → Pages** 中选择从 `main` 分支的根目录发布。游戏素材由页面直接从 `1阶`、`2阶`、`3阶`、`4阶`、`5阶` 与 `unique` 文件夹读取，无需构建步骤。
